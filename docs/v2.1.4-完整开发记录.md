## 二、核心能力

### 1. 文件系统重构（P1，2756623b，les 开发）

类 Windows 资源管理器体验：左侧多层文件夹树 + 右侧网格视图。

#### 数据模型

| 表/列 | 说明 |
|---|---|
| `file_folders`（新表） | id / project_id / parent_id（自引用，NULL=根）/ name / created_at；无限层级 |
| `files.folder_id`（新列） | 文件归属文件夹（NULL=根目录），幂等迁移（PRAGMA 检查补列） |

#### 文件夹操作

| 能力 | 规则 |
|---|---|
| 新建 | 顶部「新建文件夹」建根级；树内右键「新建子文件夹」 |
| 重命名 | 行内编辑；**同级重名**校验 |
| 换父级 | 拖拽；**防环**（不能把自己或子孙设为父级） |
| 删除 | **内容提升**：其下文件与子文件夹整体提升至被删夹父级，不级联删、不丢结构（事务内完成） |
| 审计 | 创建/更新/删除文件夹全埋点（targetType "folder"） |

#### 文件列表

- `listFiles`：folderId 过滤（folderId=root 语义）+ **名称搜索**（LIKE 转义）；排序本期不做
- `getProjectFull`：返回 folders 树 + files 带 folderId/pathExists
- 路径失效：UI 角标提示（延续既有逻辑）

#### Agent 工具（+4，59→63）

| 工具 | 说明 |
|---|---|
| `create_project_folder` | 建文件夹（根级/子级，同级重名校验） |
| `update_project_folder` | 改名 + 换父级（防环） |
| `delete_project_folder` | 删除（内容提升语义） |
| `read_project_file` | 文本类直接读（8000 字截断）；docx 复用 docxToText（tar 解压 + `<w:t>` 提取）；pdf 零依赖提取（zlib inflate + 文本操作符扫描，FlateDecode 流）；图片/未登记文件明确报错 |

`list_project_files` 增强：支持 folderId / name 过滤，输出带文件夹归属。

#### 前端

- 新增 `FolderNode.vue` 递归组件（展开/收起/选中高亮/拖拽接收）
- `FileTab.vue` 重构：左树（全部文件/根目录/多层文件夹）+ 右网格（文件夹过滤、名称搜索、路径失效角标、Ctrl/Shift 基础多选、Delete 批量删除、右键菜单、拖拽移动、登记归入当前选中夹）
- `index.vue`：透传 folders；doConfirm 支持文件夹删除与批量文件删除

## 五、遗留风险

1. **PDF 提取为简易实现**：仅 FlateDecode 文本流；CID 字体中文/扫描件/加密/LZW-JPX 流明确报「未提取到文本」，不出错数据（零依赖策略，完整支持需引入 pdf 依赖）
2. **pathExists 每文件一次磁盘检查**：文件量达千级时 getProject 会变慢（一般项目无感，量大可缓存）
3. **批量删除/移动非事务**：前端多选 Delete 与拖拽逐条调接口，中途失败部分成功（提示 N/M）
4. **文件夹视图不含子夹文件**：与资源管理器默认一致，需展开进入；「含子夹」聚合视图可后续加选项
5. **工具连接不显式 close**：项目既有工具统一模式（进程生命周期释放）
