// 状态 → 样式键（各组件既有 CSS 类后缀沿用：todo/doing/done/delay/cancel；新增 pre-start/pre-end）

## P4：齿轮弹窗与列表渲染改造

### P4-1 状态分组配置弹窗（StatusGroupConfigModal）

**涉及文件**：`frontend/src/views/Home/components/StatusGroupConfigModal.vue`（新增）、`frontend/src/api/modules/setting.js`（新增）

**目标**：7 行分组，可拖拽/上下移排序、开关显隐、选数量，改动即时生效并静默保存。

#### 步骤 1：接口模块

```js
// frontend/src/api/modules/setting.js（新增，写法对齐 modules/message.js）
import http from "../index.js";
export function getStatusGroups(opts = {}) {
  return http.get("api/settings/status-groups", { silent: true, ...opts });
}
export function updateStatusGroups(data, opts = {}) {
  return http.put("api/settings/status-groups", data, { silent: true, ...opts });
}
```

#### 步骤 2：弹窗结构（FloatPanel，对标 `RiskConfigModal.vue`）

```
┌──────────────────────────────────────────────────────────────┐
│ 状态分组配置                                            [×]  │
├──────────────────────────────────────────────────────────────┤
│ 提示：拖拽或用 ↑↓ 调整顺序；开关控制列表是否展示该组          │
│ ┌────────────────────────────────────────────────────────┐   │
│ │ ⠿ 预开始   [↑][↓]        [ 显示 ●]   数量 [全部 ▾]    │   │
│ │ ⠿ 待开始   [↑][↓]        [ 显示 ●]   数量 [全部 ▾]    │   │
│ │ ⠿ 进行中   [↑][↓]        [ 显示 ●]   数量 [10  ▾]     │   │
│ │ ⠿ 预结束 …  进行中 …  已完成 …  已取消 …  已归档(默认 ○)│   │
│ └────────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────┘
```

- 7 行数据源：本地 `GROUP_ROWS = [{ label: "预开始" }, …, { label: "已归档" }]`，顺序取配置 `order`（恰好 7 项）。
- 数量下拉固定 5 档：`[{label:"5",value:5},{label:"10",value:10},{label:"15",value:15},{label:"20",value:20},{label:"全部",value:"all"}]`，**无自定义输入**。
- 拖拽用已安装的 `vuedraggable`（`frontend/package.json` 已含 `^4.1.0`，SetCard 排序可参照）；`↑/↓` 按钮保底，禁用首/末项。

#### 步骤 3：即时生效 + 静默保存

```js
// 弹窗持有本地副本，每次变更后 300ms 防抖整份 PUT
const props = defineProps({ show: Boolean, config: { type: Object, required: true } });
const emit = defineEmits(["update:show", "update:config"]);

function touch(next) { emit("update:config", next); scheduleSave(); }

let timer = null;
function scheduleSave() {
  clearTimeout(timer);
  timer = setTimeout(async () => {
    const payload = { order: toOrder(props.config), visible: { ...props.config.visible }, limit: { ...props.config.limit } };
    let res = await updateStatusGroups(payload);           // silent
    if (!res?.ok) res = await updateStatusGroups(payload); // 静默重试一次
    // 仍失败：什么都不做（不 toast），保留页面当前展示，下次调整时重写
  }, 300);
}
```

- 保存内容只含 7 个分组键（预开始/待开始/进行中/预结束/已完成/已取消/已归档），`已延期` 不进配置（它随待开始组渲染与计数）。
- 关闭弹窗时 `clearTimeout` 并 flush 一次（避免最后一次调整丢失）。

**风险点**：
- 整份覆盖写入是需求硬约束：不能只 PUT 被改的那一行，也不能在防抖期间拼接两次变更（用本地完整 state 生成 payload）。
- 不要用 `toast`；接口默认 `silent: true`，任何失败都不弹。

```js
// 前端兜底默认值：必须与后端 defaultStatusGroups() 逐字一致（契约快照见对齐文档）
const DEFAULT_CONFIG = {
  order: ["预开始", "待开始", "进行中", "预结束", "已完成", "已取消", "已归档"],
  visible: { 预开始: true, 待开始: true, 进行中: true, 预结束: true, 已完成: true, 已取消: true, 已归档: false },
  limit: { 预开始: "all", 待开始: "all", 进行中: "all", 预结束: "all", 已完成: "all", 已取消: "all", 已归档: "all" },
};
const statusGroups = ref(structuredClone(DEFAULT_CONFIG));
async function loadStatusGroups() {
  const res = await getStatusGroups();
  if (res?.ok && res.data?.config) statusGroups.value = res.data.config;
}
onMounted(loadStatusGroups);

const GROUP_DEFS = [
  { key: "pre-start", label: "预开始", statuses: ["预开始"] },
  { key: "todo",      label: "待开始", statuses: ["待开始", "已延期"] }, // 已延期并入本组
  { key: "doing",     label: "进行中", statuses: ["进行中"] },
  { key: "pre-end",   label: "预结束", statuses: ["预结束"] },
  { key: "done",      label: "已完成", statuses: ["已完成"] },
  { key: "cancel",    label: "已取消", statuses: ["已取消"] },
  { key: "archived",  label: "已归档", statuses: [] },
];
```

`groupedProjects`（现 `:128-146`）保留「按 `computeDisplayStatus` 分组 + 收藏/时间排序」的分拣逻辑，仅把输出键对齐 `GROUP_DEFS.key`（新增 `pre-start`、`pre-end` 两组，`todo` 继续合并 `已延期`）。

```js
// 配置顺序 → 7 组；配置里只有 7 个分组键，旧配置残留的其它键在服务端已被丢弃
const orderedGroups = computed(() => {
  const byKey = new Map(groupedProjects.value.map((g) => [g.key, g.items]));
  const byLabel = new Map(GROUP_DEFS.map((d) => [d.label, d]));
  const seen = new Set();
  const out = [];
  for (const name of statusGroups.value.order) {
    const def = byLabel.get(name);
    if (!def || seen.has(def.key)) continue;
    seen.add(def.key);
    out.push({ ...def, items: byKey.get(def.key) || [] });
  }
  for (const def of GROUP_DEFS) if (!seen.has(def.key)) out.push({ ...def, items: byKey.get(def.key) || [] });
  return out;
});

// 渲染：显隐 + 截断 + 是否出「查看全部」
const renderGroups = computed(() => orderedGroups.value
  .filter((g) => statusGroups.value.visible[g.label] !== false)
  .map((g) => {
    const limit = statusGroups.value.limit[g.label];
    const capped = limit === "all" ? g.items.length : Math.min(limit, g.items.length);
    return { ...g, renderItems: g.items.slice(0, capped), total: g.items.length,
             more: limit !== "all" && g.items.length > limit };
  }));
```

| `{{ group.items.length }}` 组头计数 | `{{ group.total }}`（总数，不随 limit 变，与需求 3.6 一致） |
| `v-for="p in group.items"` | `v-for="p in group.renderItems"` |
| 底部单独一段 `.archived-more` | 已归档组：`visible=true` 时按配置渲染卡片（含 `more` 按钮）；`visible=false`（默认）时不渲染卡片，但**入口块独立渲染**（`archivedTotal > 0` 即显示），文案仍为「查看全部已归档项目（N 条）」 |
| 其余组底部无入口 | `group.more` 为真时出 `查看全部{{ group.label }}项目（{{ group.total }} 条）>` |
| 无「全隐藏」分支 | 新增：`allGroupsHidden`（7 组 `visible` 全为 false）→ 空态「所有状态分组已隐藏，点右上角齿轮重新开启」 |

| `showFilters` | Boolean | `true` | `false` 时整段搜索栏（`:9-42`）不渲染（分组「查看全部」的筛选已在列表页完成） |
| `showRestore` | Boolean | `true` | `false` 时「操作」列（恢复按钮）不渲染 |
| `emptyText` | String | `"没有匹配的已归档项目"` | 表格空态文案 |

#### 步骤 2：ProjectPanel 统一入口

```js
const listModal = reactive({ show: false, title: "", projects: [], showFilters: true, showRestore: true });
function openGroupAll(g) {
  const archived = g.key === "archived";
  Object.assign(listModal, {
    show: true,
    title: archived ? "已归档项目" : `全部${g.label}项目`,
    projects: g.items,                       // 全量，未截断
    showFilters: archived,                   // 归档保留原筛选栏
    showRestore: archived,                   // 仅归档可恢复
  });
}
function onListOpen(id) { listModal.show = false; emit("open-project", id); }
```

```html
<ArchivedProjectsModal
  :show="listModal.show" :title="listModal.title" :projects="listModal.projects" :sets="sets"
  :show-filters="listModal.showFilters" :show-restore="listModal.showRestore"
  @close="listModal.show = false" @open="onListOpen" @restore="restoreFromModal"
/>
```

- 继承外部筛选：`projects` 直接取 `g.items`，其上游是 `filteredProjects`（当前项目集 `filSetId` + 搜索 `search`）；页面级状态筛选当前不存在，若后续新增只需在 `filteredProjects` 收口。
- 条目点击 → `emit('open-project', id)`，与卡片点击一致（`ArchivedProjectsModal` 内已有 `@click="emit('open', row.id)"`）。
- 关闭不残留遮罩：沿用 `FloatPanel` 的 `update:model-value` 链路（`:6`），不要另写 `v-if` 直插。

**风险点**：
- 归档分组默认 `visible=false`：底部「查看全部已归档项目（N 条）」入口**常显**（已确定，依据需求 3.5「原入口行为不变」），不随归档组显隐变化；实现上入口是 `renderGroups` 循环外的独立块（见 P4-2 模板骨架）。
- `openGroupAll` 传的是 `g.items` 全量；已归档走 `archivedGroup`，标题固定「已归档项目」并保留筛选栏与恢复列。
- 弹窗内 `pageSize=10` 分页与列表 `limit` 是两套语义，不要合并。
