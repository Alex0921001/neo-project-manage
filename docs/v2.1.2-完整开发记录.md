## 二、核心能力

### 1. 工具类补齐（`7c717e6`，工具 47→51）

| 工具 | 说明 |
|---|---|
| `confirm_annotations` | 批量确认批注。支持 ids / taskId / project 三范围，事务执行 + 已完成任务冻结校验，审计留痕 |
| `register_project_file` | 按路径登记文件资产（封装 data.addFile） |
| `import_plan_file` | txt/md/docx 解析预览（返回 title/content JSON），`autoCreate=true` 可直建方案 |
| `list_project_risks` | 跨项目风险汇总（可指定 projectSetId + includeNoRisk），返回 summary 等级统计 + 各项目风险明细 |

配套数据层：

- `confirmAnnotations(projectId, { taskId?, ids? })`：ids 优先（跨项目校验"部分批注不存在或不属于该项目"）→ taskId 该任务未确认 → 项目全部未确认
- `addDays(d, days)` 工具函数（UTC 显式解析），`listTasks` 过滤器新增 `nearDeadlineDays`（未完成 + endDate 在 [today, today+N]）

### 2. 查询输出增强（`7c717e6`）

- `list-projects`：渲染补 `[方案: planCount]`
- `list-tasks`：新增 `nearDeadlineDays` 参数（临近截止任务筛选）
- `get-project`：`view=summary` 轻量模式，跳过批注/文件/备注明细，子任务递归保留，token 大幅减少

### 3. 任务排序三模式（`50f6fd0` → `9b0c392` → `e66bd66` → `5365d1d`）

| 模式 | 排序规则 | 拖拽 |
|---|---|---|
| 默认排序 | 原拖拽序（index_num） | 可拖拽（把手显示） |
| 时间排序 | 开始时间升序，无日期排最后 | 禁用（把手灰显） |
| 等级排序 | P0 → P5，同等级保持原序 | 禁用（把手灰显） |

实现要点：

- `sortTree(tasks, mode)` 递归排序：子任务 / 孙任务按同一规则（不改原对象，重建 subtasks 引用）
- 排序控件：展开按钮左侧**下拉选择**（默认排序 / 时间排序 / 等级排序，选项带规则提示），31px 高度与方案/审计筛选下拉一致，文字 12px/600 与相邻按钮对齐
- 拖拽禁用：非默认排序时 draggable `:disabled` + TaskCard `dragDisabled` prop 隐藏拖拽把手

### 4. 内层任务定位修复（`50f6fd0`）

**根因**：`scrollToTaskById` 直接 querySelector 目标，内层任务祖先未展开时 DOM 未渲染 → 定位失败。

**修复**：定位前先 `findTaskPath(props.tasks, taskId)` 找祖先链 → `forceExpandIds` 强制展开（TaskCard watch 逐层展开）→ 双 nextTick（展开 + 子任务渲染各占一轮）后滚动 + 琥珀闪烁。日历弹窗跳转内层任务（含孙任务）链路打通。
