# 项目管理插件 v1.3.0 变更总结

> 版本：1.2.0 → 1.3.0 ｜ 分支：feature/v1.3.0 ｜ 日期：2026-08-09/10

## 一、首页

### 项目卡片改「便利贴」风格
- 白纸条 + 顶部状态色胶带（透明、两端锯齿撕口），胶带颜色映射四状态：待开始橙 / 进行中蓝 / 已完成绿 / 已延期红
- 卡片四行布局：项目名称 → 起止时间（带年份）→ 进度条（颜色跟随状态色）→ 统计行（任务 x/y · 文件 · 备注，SVG 线形图标）
- 描述：灰色虚线框，固定前 100 字 + `...`；无描述显示「这个用户很懒，还没有添加描述。」
- 卡片固定高度等高（262px）；操作按钮（复制 ID / 编辑 / 删除）移入**右键菜单**，同一时间只允许一个菜单打开（模块级状态共享），外部点击 / Esc / 滚动关闭
- 搜索框改为 header 常显（带清空按钮），去掉展开式搜索按钮

### 项目集 tabs
- 侧栏 → 顶部 tabs：全部项目 + 各项目集（带计数），激活态黑字加粗 + 淡灰背景
- 右键 tab 管理（编辑/删除），管理弹窗内回车即新增、行内编辑、拖拽排序（前端内存）
- 排序持久化待后端加 sort 字段（业务层改动，未做）

## 二、详情页

- **移除右上角 sticky 日历**（日历 tab 保留）
- **面包屑**：返回箭头 + 全部项目 / 项目集 / 项目名（详情页 + 大日历页统一）
- 详情卡：30px 大标题 + 状态下拉（白底控件）+ 复制/编辑/删除按钮（白底）
- 描述**纯文本展示**（div，非富文本渲染）；新建/编辑弹窗描述改为 textarea（历史富文本自动转纯文本回填）
- 元数据行：计划周期 / 剩余时间 / 成员（tag 展示，前 3 + N）/ 进度条（颜色随状态色）
- 任务/文件/备注 tab 激活样式对齐项目集 tabs（黑字加粗 + 淡灰背景）
- 删除项目入口（详情卡垃圾桶按钮 → ConfirmModal → 删除后回列表）

## 三、弹窗统一

- 项目弹窗 4 行布局：名称 / 项目集+状态 / 计划周期+成员 / 描述
- 任务弹窗 4 行布局：名称 / 起止日期+成员 / 关联文件（恒显示，无文件时禁用提示）/ 简述
- 所有弹窗确认按钮统一**黑底白字**（全局 `.btn-save` 类，注意 el-dialog append-to-body 需非 scoped 全局样式）
- 空状态统一（任务/文件对齐备注）：圆形图标 + 标题 + 副标题 + 大按钮

## 四、日历

- 任务日历 tab：**项目色条**（当前项目起止范围，蓝色）+ **任务色条**（糖果色）
- 筛选（全部/未完成/已完成）**只作用于任务色条**，项目色条恒显示、不可点击
- 任务颜色按 **ID 哈希固定**（pickPaletteColor），筛选切换不跳色
- 糖果色：饱和度对齐状态色（C 0.19-0.22）+ 75% 半透明

## 五、开发环境 / 修复

- dev server 本地数据源：devmock.js（真实 SQLite 只读 + 内存 overlay，写操作不落库）
- 修复 devmock 删除 bug：overlay 循环未过滤 delSets/delProjects（新增的集/项目删除后又回来）
- devmock 补充 pick-file / open-file 桌面能力提示（浏览器预览明确报错而非 404）
- 文件选择按钮：try/finally 复位 + 12s 超时提醒（后端 execSync 弹系统对话框，阻塞最长 60s）

## 踩坑记录（新增）

1. **`<script setup>` 顶层变量是实例级的**：每组件实例重新声明，跨实例共享状态需提到普通 `<script>` 块（模块级）——右键菜单互斥就因此失效过一次
2. **el-dialog append-to-body 后 scoped + :deep() 样式失效**：确认按钮黑底白字必须用非 scoped 全局 style
3. **v-if/v-else 交错编译错误**：多个图标切换不能 v-if 接 v-if 再接 v-else，需全部用独立 v-if 条件
4. **execSync 弹系统对话框阻塞**：pick-file 请求可能挂起 60s，前端必须 try/finally + 超时提示
5. **el-form-item__content 是 flex 布局**：提示文字要独立一行需 `flex-basis: 100%`（display:block 不生效）
6. **FullCalendar 左闭右开**：事件 end 需 dayjs +1 天（沿用既有约定）
