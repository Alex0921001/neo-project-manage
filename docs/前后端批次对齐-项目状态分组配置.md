## 契约快照（前后端对齐用，改动需双方同步）

**配置结构**（settings 表 `key = projectStatusGroups`，JSON 字符串）

```json
{
  "order": ["预开始", "待开始", "进行中", "预结束", "已完成", "已取消", "已归档"],
  "visible": { "预开始": true, "待开始": true, "进行中": true, "预结束": true,
               "已完成": true, "已取消": true, "已归档": false },
  "limit": { "预开始": "all", "待开始": "all", "进行中": "all", "预结束": "all",
             "已完成": "all", "已取消": "all", "已归档": "all" }
}
```

> 7 个键，键即分组；`已延期` 不占键、不进配置，随「待开始」组渲染与计数。

| 契约点 | 后端 | 前端 | 一致性要求 |
| --- | --- | --- | --- |
| 键集合 | 7 个分组名（预开始/待开始/进行中/预结束/已完成/已取消/已归档） | 同左；弹窗 7 行无第 8 行 | 前端 PUT 只发这 7 键，`已延期` 不出现 |
| 分组数 | 归一后恒为 7 键 | 弹窗 7 行 | 7 组：预开始/待开始（含已延期）/进行中/预结束/已完成/已取消/已归档 |
| `limit` 值域 | `5/10/15/20/"all"` | 下拉同 5 档，无自定义输入 | 非法值后端回落「原有效值」，前端不发送非法值 |
| 写入语义 | 整份覆盖，不做局部合并 | 防抖后整份 PUT（含未改动组） | 前端不可只发被改的行 |
| 响应形态 | `{ ok, data: { config } }` | 读：`res.data.config`；写：响应可忽略 | 与 `api/messages/config` 形态一致 |
| 默认值来源 | `defaultStatusGroups()` | 本地兜底默认（接口失败时用） | 两处数值必须逐字一致 |
| 失败策略 | 400 + `error` 文案 | `silent: true`，重试一次，仍失败不提示、保留当前展示 | 保存全程无 message |
| 计数口径 | 统计不受 `limit` 影响 | 标题 `filteredProjects.length`、Tab `projectSets.projectCount` 不变 | `limit` 只在渲染层 `slice` |

**状态值域**：`预开始 / 待开始 / 进行中 / 预结束 / 已完成 / 已取消`（存储态 6）；`已延期` 仅展示态，不可作为 `status` 参数写入或筛选。

**样式层（拟定值，可调，不阻塞开发）**：工具图标 `预开始 🟡 / 预结束 🟠`；前端状态类 `.status-pre-start`（淡黄）/ `.status-pre-end`（橙）。

## 建议开发顺序

1. **P1 后端**：状态白名单 + 工具枚举，跑 `node --test "scripts/test/*.test.mjs"`，独立合入。
2. **P2 后端**：配置读写 + 路由；与 P1 可并行，契约冻结后通知前端（接口路径、默认 JSON、错误码）。
3. **P3 前端**：常量/token → 下拉 → 卡片/弹窗/审计/日历；验收依赖 P1 已合并。
4. **P4 前端**：先弹窗与接口对接（能读能写、静默保存），再改 `ProjectPanel` 渲染，最后泛化归档弹窗。
5. **P5 联合回归**：后端全量测试 + 前端 vitest + `npm run build:v2` + `npm run validate:v2`，逐条核对需求第 5 节。

## 联调检查点

| # | 检查点 | 前端动作 | 后端断言 |
| --- | --- | --- | --- |
| 1 | 新状态可保存 | 新建项目选「预开始」 | `POST /api/projects` 返回 `status: "预开始"`；`computeStatus` 原样返回 |
| 2 | 非法状态被拒 | 直连 PUT `status: "已延期"` | 400 `项目状态不合法` |
| 3 | 工具链路 | Agent `update_project` 传「预结束」 | 成功；`list_projects` 图标为 🟠 |
| 4 | 配置首次读取 | 打开弹窗（无历史配置） | 返回默认值：7 组顺序、已归档 `false`、`limit` 全 `"all"` |
| 5 | 配置写入 | 把「进行中」调为 5 并上移 | `settings.value` 为合法 JSON；再 GET 一致；返回体仅 7 键 |
| 6 | 旧配置降级 | 库内保留含 `已延期` 的旧 JSON | GET 输出仅 7 键，不报错 |
| 7 | 脏值回落 | 手改库写 `limit: {"进行中": 7}` | GET 回落原有效值/`"all"`，不抛错 |
| 8 | 静默保存 | 任意调整 | 无 toast；network 面板 PUT 200 |
| 9 | 已归档入口 | 归档分组默认隐藏 | 底部「查看全部已归档项目（N 条）」常显，点开为同一弹窗组件 |
