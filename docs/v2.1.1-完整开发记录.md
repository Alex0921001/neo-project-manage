### 2. 方案文件导入（txt / md / docx）

- 后端 `lib/plan-import.js`：`POST /api/projects/:id/plans/import`（multipart）
  - txt：Node 原生读 utf8，空行分段
  - md：手写轻量转换器（标题 / 列表 / 代码块 / 引用 / 链接 / 表格 / 行内标记）
  - docx：系统 tar（Windows 内置 bsdtar）解压 `word/document.xml`，按段落提取 `<w:t>` 文本，标题样式映射 h1-h6
  - 限制：仅 txt / md / markdown / docx，单文件 ≤ 5MB；非支持类型拒绝
- 前端：PlanModal 编辑态标题右侧「从文件导入」按钮 → 解析预填标题（取文件名）+ 内容，可修正后保存

### 3. 日历统一为弹窗（999ac39 → ece1309 → 495f7da → eceed8b）

- 新建 `CalendarModal`（FloatPanel + CalendarWidget 复用），两种模式：
  - 全项目日历（列表页「前往日历」按钮，原独立路由视图删除）
  - 单项目任务日历（详情页「前往日历 >」按钮，仅任务 tab 显示，位置在新建按钮右侧）
- 跳转后立即关闭弹窗（select/select-task 先关再跳）
- 自适应：非 compact 高度改 100% + ResizeObserver 驱动 FullCalendar `updateSize()`（单元格随弹窗伸缩）

### 4. 风险规则配置化（项目级）（3dc085d）

- 数据层：`projects.risk_config` 列（幂等迁移 `migrateRiskConfig`，不 bump SCHEMA_VERSION）；`getRiskConfig` / `updateRiskConfig`（白名单校验：规则 key / 字段类型 / 等级枚举，非法值回退默认）
- 7 条规则全可配：**开关 + 阈值 + 等级**（默认 = 原硬编码值，老项目无感升级）
- REST：`GET / PUT /api/projects/:id/risk-config`，写操作留审计
- 前端：概览页「风险」标题旁齿轮按钮 → `RiskConfigModal`（分组标题：项目风险 / 任务风险 / 批注风险；内容区滚动 + footer 固定）
- summary / nextSteps 硬编码阈值同步接配置（与风险列表口径一致）

### 5. 风险批注聚合 + 类别排序

- **聚合**（3dc085d）：规则 7 由「每条 risk 批注一条风险」改为聚合一条（desc = N 条风险批注，明细在 tasks 带 content/confirmed）；前端气泡展示明细 + 已确认/待确认徽标，点击定位批注
- **类别排序**（e8f117f）：risks 加 `category` 标记（project / task / annotation），排序双键（类别优先 项目→任务→批注，类内等级 high→medium→low）；配置弹窗同步分组展示
