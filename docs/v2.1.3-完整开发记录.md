## 二、核心能力

### 1. tab 栏配置化（P0，980d6245）

tab 列表从硬编码改为数据驱动，支持调序、显隐、项目级/全局级配置：

| 能力 | 说明 |
|---|---|
| 7 tab 固定集合 | 任务 / 需求 / 方案 / 文件 / 知识 / 备注 / 审计 |
| 默认顺序 | 任务 → 需求 → 方案 → 文件 → 知识 → 备注 → 审计 |
| 拖拽调序 | tab 条直接拖拽（vuedraggable），松手保存到全局配置 |
| 右键菜单 | tab 右键 → 「Tab 设置…」/「重置默认顺序」 |
| 设置弹窗 | 显隐勾选 + 上移/下移 + 三操作方式：取消（丢弃）/ 全局应用 / 本项目应用（确认后才生效，不实时） |
| 生效优先级 | 本项目配置 > 全局配置 > 默认顺序 |
| 存储 | localStorage 双 key：`neo-pm-tab-config`（全局）/ `neo-pm-tab-config-{projectId}`（项目级） |
| 约束 | 至少保留 1 个可见 tab |

新增组件 `TabConfigModal.vue`；`index.vue` 内 `TAB_DEFS` + `tabList` computed + `tabDragList` ref（vuedraggable v-model），拖拽结束写全局配置。

### 2. 需求管理（P1，d5070bcc）

#### 数据模型

| 表 | 字段 | 说明 |
|---|---|---|
| `requirements` | id / project_id / name / description / status / priority / created_at | 三态：待处理 → 已完成 / 已取消 |
| `requirement_plans` | requirement_id / plan_id | 需求 ↔ 方案多对多中间表（迁移幂等） |

状态机约束：

- 新需求默认「待处理」，priority 默认 P3
- 状态流转只允许从「待处理」出发；已完成/已取消**冻结**（不可编辑、不可再流转）
- 名称必填 ≤ 50 字

#### 分层实现

| 层 | 内容 |
|---|---|
| 数据层 | `createRequirement` / `updateRequirement` / `updateRequirementStatus` / `deleteRequirement` / `listRequirements`（分页 + status/keyword + planCount/planIds）/ `getRequirement`（含方案明细）/ `linkRequirementPlans` / `unlinkRequirementPlans`（replace 语义走事务） |
| REST | `/api/projects/:projectId/requirements` CRUD + `/status` 流转 + `/plans` 关联/解除（8 接口，`routes/modules/requirements.js`） |
| 工具层 | 8 个：`create_requirement` / `update_requirement` / `update_requirement_status` / `delete_requirement` / `list_requirements` / `get_requirement` / `link_requirement_plans` / `unlink_requirement_plans`（工具 51→59） |
| 前端 | `RequirementTab.vue`：筛选（状态）+ 搜索 + 分页 + 富文本简述 + 方案多选关联；状态徽标染色 + 已完成划线 |
| 双向展示 | 方案详情（PlanModal）反向展示「满足的需求」（状态圆点 + 名称 + 状态） |
| 审计 | 创建/更新/状态流转/关联/解除/删除 全埋点 |
