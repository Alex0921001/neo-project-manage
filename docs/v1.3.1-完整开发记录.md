## 二、嵌套任务状态同步（v1.3.1 核心）

### 规则（鹏哥拍板）

| 操作 | 校验 | 方向 |
|---|---|---|
| 子任务完成（done=true） | 无父任务约束（允许子任务先完成） | 上行不拦 |
| 子任务激活（done=false） | **父任务必须已激活**（父任务仍 done → 阻止） | 下行必须同步 |
| 父任务完成 | 原有 countIncompleteDescendants 保护（子任务未完成 → 阻止） | 既有 |

语义：**未完成状态只能从父任务向下同步**。父任务已完成时，子任务不能单独激活；必须先激活父任务，再激活子任务。

### 实现

- 前端 `TaskTab.vue` markTaskDone：done=false 分支查 `findTaskInTree(props.tasks, task.parentTaskId)`，父任务 done 则 toast + return
- 后端 `lib/data.js` updateTask：`!data.done && cur.parent_task_id` 时查库校验父任务 done，拒绝则 throw（防前端绕过 + agent 工具调用）

## 五、错误提示拦截重构（本次最大改造）

### 背景

后端业务错误（ok=false）时，前端原来用**右下角大红色浮窗**（toast.js 自绘 div），样式丑；且部分调用存在「api 拦截 + 手动 toast」**双重弹错**。

### 改造

| 文件 | 改动 |
|---|---|
| `frontend/src/toast.js` | 用 **Element Plus ElMessage** 替代自绘红色 div；错误 4s + 关闭按钮；600ms 内容去重 |
| `frontend/src/api.js` | **自动拦截** `res.ok===false` → `ElMessage.error`；新增 `opts.silent:true` 跳过拦截 |
| 10 个 .vue 文件 | 22 处手动 toast 的 api 调用配套 `silent: true`，避免双重弹错 |

### 防重复弹机制

- api 默认拦截弹一次；调用方手动 toast 也弹一次 → 双重
- 修复：手动 toast 的调用传 `silent: true`（api 不弹，由调用方弹）
- 剩余少量 api 拦截 + 手动 toast 并存的场景，由 toast.js 内部 600ms 内容去重兜底

### 修复的具体 bug

- **「无法激活子任务」提示弹出两遍**：前端 props.tasks 缓存过期（父任务显示未完成），前端校验放行 → 调 api → 后端真实校验拒绝 → api 拦截弹一次 + markTaskDone 手动弹一次 = 两遍。已通过 silent:true 修复
- **ElMessage 右上角 "2"**：`grouping: true` 合并相同消息并计数 → 改为 `grouping: false`

## 六、便利贴文案

## 踩坑记录

1. **api 拦截 + 手动 toast 双重弹错**：新增全局拦截器后，所有 `else toast(res.error || "失败", "error")` 的地方都会双弹。必须给手动 toast 的 api 调用传 `silent: true`
2. **ElMessage grouping 计数**：`grouping: true` 会合并相同消息并在右上角显示计数（如 "2"），视觉困惑
3. **前端缓存过期导致前后端校验不一致**：props.tasks 是最后一次 load() 的快照，父任务 done 状态可能滞后于数据库。前端校验通过不代表后端会通过，后端校验是最后防线
4. **Windows mmap 锁反复出现**：better_sqlite3.node 被 mmap 锁定，reload/dev slot 操作需重启 Hana；临时绕过：`ren` 移走旧 dev slot 目录再 install（遗留 OLD 目录待 OS 回收）

## 七、发版后修复（v1.3.1 补充）

### 7.1 项目集拖拽排序持久化

- **问题**：拖动项目集排序只改内存态，刷新后还原
- **后端**：
  - db.js schema v4：project_sets 加 `sort INTEGER`，迁移按 created_at 补值
  - data.js：listProjectSets 改 `ORDER BY sort IS NULL, sort, created_at`；createProjectSet 自动 sort=max+1；新增 reorderProjectSets(ids) 事务批量重写

- **前端**：Home/index.vue onReorder 调 reorder API 持久化，失败回滚

### 7.2 子任务跨父级拖拽（空放置区）

- **问题**：目标一级任务无子任务时没有 draggable 放置区，无法把子任务拖入
- **修复**：TaskCard.vue depth=0 且无子任务时也渲染空 draggable（subtask-empty 类），hover 显示「拖入任务可添加为子任务」提示；搜索态不渲染
