## 一、版本定位

| 维度 | V1.x（现状） | V2.0（目标） |
|---|---|---|
| 角色 | 任务管理工具 | 项目协作空间 |
| 数据 | 项目/任务/批注/文件登记 | + 会话关联/文件索引/决策风险/自动总结 |

## 二、核心能力（18 个阶段）

### Phase 0-1：schema v5 迁移（S1）

- SCHEMA_VERSION 4 → 5，migrateToV5 幂等迁移
- annotations 加 kind（TEXT DEFAULT 'note'）
- files 加 size/ext/indexed/digest
- projects 加 session_ids（TEXT DEFAULT '[]'）
- 新建 project_summaries 表（id/project_id/content/created_at/source，外键级联）

### 批注类型化（S2-S3）

- 便利贴 4 类型：note 备注 / decision 决策 / risk 风险 / milestone 节点
- 数据层 + 4 工具 + REST 全链路透传 kind，COALESCE 兜底老数据
- 前端类型下拉 + 四色着色（决策蓝/风险红/节点金/备注黄）+ 筛选 chips

### 文件资产化（S4-S6）

- 登记文件自动读 size/ext（fs stat），digest 可选（限 500 字），路径失效防御
- 新工具 list_project_files / get_project_file
- 前端文件 tab 显示类型/大小/摘要

### 会话关联 + 总结持久化（S7-S9）

- projects.session_ids JSON 数组：link/list/unlink 三工具
- project_summaries：saveProjectSummary / getProjectSummaries（倒序，limit）
- 里程碑快捷按钮「记一个节点」（预填本地日期）

### 分析能力（S10-S12，核心价值）

- summarizeProject：固定模板 JSON（进度/完成/未完成/延期/风险/待确认批注/文件/下一步）
- 6 条风险规则：延期 high / 逼近截止 medium / 批注积压 medium / 项目逾期 high / 任务无日期 low / 项目停滞 medium
- summarize_project 工具（10 段 markdown）
- askProject(scope)：summary/risks/decisions/timeline/files/all + ask_project 工具
- REST：GET /api/projects/:id/summary + GET /api/projects/:id/summaries

### 前端整合（S13-S14）

- ProjectOverview.vue 概览面板：进度条/延期/风险分级/待确认/下一步，防并发 + 优雅降级
- 历史总结时间线：懒加载 + 缓存，projectId 切换重置

- 去掉编辑模式：点击内容就地编辑（textarea 同底色无边框），失焦/Ctrl+Enter 保存、Esc 取消、空内容回退原文、保存静默

- 下拉菜单无圆角无阴影，hover 项才有阴影；textarea 隐藏拖拽手柄（resize: none）

## 八、踩坑记录

1. **createTask 不接收 done 参数**：完成状态必须走 updateTask 设置，测试脚本直接传 done 被忽略（PM 复测时踩过）
2. **老数据 kind=NULL 筛选漏掉**：SQL 用 `kind = 'note'` 匹配不到 NULL，必须 `COALESCE(kind,'note') = ?` 与读取兜底语义统一
3. **notes.created_at 是纯日期**（非 ISO）：timeline 合并排序需 timeToMillis 归一化两种格式
4. **Windows 临时目录 EPERM**：better-sqlite3 WAL 句柄未释放，测试脚本删除临时目录报错（测试逻辑不受影响，收尾容错即可）
5. **Hono 由平台注入**：不在依赖中，路由无法真起 HTTP 测试，用「fake app 捕获注册 + 直调 handler」验证
6. **manifest tools 是显式声明列表**：新工具必须注册才被平台加载（S5 发现，非自动扫描）
7. **dev 槽位 lib 不完整**：install 时 better_sqlite3 mmap 锁中断导致 db.js 缺失，computeStatus 改动不生效；重装 + 校验完整性解决
8. **中文文件名 URL 编码**：/icons/撒花.png 编码后路由 param 不匹配 → 改英文名 confetti.png
9. **图标 404 根因**：img src 必须带插件前缀 /api/plugins/{id}/ + resolveAssetUrl 处理凭据
10. **absolute 定位输入框重叠**：toolbar 叠在 textarea 上文字会重叠，改 flex 容器（textarea + toolbar 正常流）根治
11. **vuedraggable 搜索过滤不生效**：:list 绑全量数组，搜索态应绑过滤结果
