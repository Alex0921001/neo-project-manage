# v3.2.0

项目管理 App 的正式发布版本，新增项目复制、卡片内直接编辑描述，并调整卡片交互。

## 本版新增

**复制项目**

项目卡片右键菜单新增「复制项目」。弹窗与新建项目一致，所有字段预填源项目内容，可改名称、项目集、状态、计划周期、成员与描述。下半部分用复选框选择要复制的内容：任务、需求、方案、验证、文件、备注，按需勾选。

复制后的处理：

| 内容 | 处理 |
| --- | --- |
| 任务 | 保留树形层级、优先级、负责人、日期；完成状态重置为未完成 |
| 批注 | 随任务一起复制 |
| 需求 | 内容保留，状态重置为「待处理」，优先级保留 |
| 方案 | 正文保留，状态重置为「草稿」 |
| 验证 | 验证卡与验证项都复制，勾选状态、证据、勾选人全部重置 |
| 文件 | 记录复制，沿用原文件路径 |
| 备注 | 原样复制 |
| 关联关系 | 需求与方案、任务与方案、验证与任务，按新 ID 重建 |

文件采用记录复制，不占用额外磁盘空间。副本项目的文件列表直接引用原文件，与原项目共享同一份磁盘文件。

**卡片描述直接编辑**

项目卡片上的描述区域可直接点击编辑，光标定位到点击位置，失焦保存，Esc 放弃。无边框设计，编辑前后字体、字号、行距与横格线对齐完全一致，不会出现跳动。

**描述保留换行与空格**

描述文本框中的回车与缩进现在会原样呈现在卡片上，重新打开编辑也不会丢失。

## 本版调整

| 项 | 调整 |
| --- | --- |
| 卡片跳转 | 单击改为双击打开项目详情，避免误触 |
| 装订孔 | 底色改为页面背景色，呈现穿透效果 |
| hover 动效 | 去掉卡片倾斜旋转，仅保留阴影与层级变化 |

## 安装

从下方附件下载 `app-neo-project-manage-v2-3.2.0.zip`，在 Hana 中安装。`entry.json` 为市场同步用的元数据文件。

已有数据直接沿用，schema 未变更，无需迁移。

## 权限声明

权限未变，仍为 5 项：

| 权限 | 用途 |
| --- | --- |
| `app/resources.read` | 读取应用自身资源文件 |
| `app.tools.expose-to-model` | 向 Agent 暴露项目管理工具 |
| `app/process.spawn` | 调用本地进程完成导出等操作 |
| `app/ui.open-external` | 在系统浏览器中打开外部链接 |
| `app/ui.clipboard-write` | 复制项目编号、任务内容等文本到剪贴板 |
