# v3.1.0

项目管理 App 的正式发布版本，新增两个前置状态与列表分组配置能力。

## 本版新增

**两个新状态**

项目状态从 4 个扩展为 6 个，新增「预开始」与「预结束」。二者是可手动选择的真实状态，与「待开始」「进行中」同级，写入数据库；「已延期」仍是按计划日期计算的展示态，判定逻辑未变。

**状态分组配置**

项目列表标题右侧新增齿轮入口，可配置 7 个状态分组的展示方式：

- 顺序：拖动行首手柄调整，松手即生效
- 显隐：逐组开关
- 数量：每组可选 5 / 10 / 15 / 20 / 全部，超出部分折叠为「查看全部项目（n 条）」入口

配置为全局一份，改动即时生效并自动保存。已归档分组同样纳入配置，不再占据独立的常显入口。

**状态色**

预开始使用淡蓝，预结束使用淡绿，与进行中的蓝、已完成的绿在亮度与饱和度上区分。

## 安装

从下方附件下载 `app-neo-project-manage-v2-3.1.0.zip` 安装包，在 Hana 中安装。`entry.json` 为该包的元数据文件，市场同步时使用。

已有数据无需迁移：数据库位于应用数据目录，安装后自动接管原有数据库，schema 版本 12。

## 权限声明

| 权限 | 用途 |
|---|---|
| `app/resources.read` | 读取应用自身资源文件 |
| `app/tools.expose-to-model` | 向 Agent 暴露项目管理工具，供对话内读写项目数据 |
| `app/process.spawn` | 调用本地进程完成导出等操作 |
| `app/ui.open-external` | 在系统浏览器中打开外部链接 |
| `app/ui.clipboard-write` | 复制项目编号、任务内容等文本到剪贴板 |
